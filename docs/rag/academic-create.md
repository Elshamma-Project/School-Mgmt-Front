## FR

### Création

Renseignez les champs obligatoires. Les codes (niveau, matière, groupe) sont stables : évitez de les changer après coup.

- Niveau : code, libellés FR/EN, cycle et section
- Classe : année scolaire + niveau ; langue des documents
- Matière : catalogue bilingue (ACADEMIC ou ACTIVITY)
- Groupe : bloc de sous-total bulletin, ordre d’affichage
- Salle : type et capacité optionnelle

## EN

### Create

Fill required fields. Codes (level, subject, group) are stable — avoid changing them later.

- Level: code, FR/EN labels, cycle and section
- Class: school year + level; document language
- Subject: bilingual catalogue (ACADEMIC or ACTIVITY)
- Group: report-card subtotal block, display order
- Room: type and optional capacity
