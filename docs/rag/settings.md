## FR

### Qui peut modifier

Les paramètres de l’établissement (année, logo, identité, documents) sont consultables par le personnel. Seul le **directeur** peut les modifier.

### Année scolaire

Une seule année est courante. Sans choix manuel, le système sélectionne automatiquement celle qui contient la date du jour. Vous pouvez créer l’année suivante (ex. 2026-2027) sans la rendre courante tout de suite — utile pour préparer la rentrée — puis la définir comme courante au moment voulu.

### Logo de l’établissement

Le logo est utilisé dans l’interface (menu), les bulletins, l’emploi du temps et les autres documents. Formats acceptés : JPEG, PNG, WebP ou SVG (max. 2 Mo).

### Identité et documents

Sur les bulletins, l’en-tête suit le modèle officiel : colonne **FR** | **logo** | colonne **EN**. Chaque colonne reprend république, devise, ministère, délégations régionale et départementale, puis le nom de l’établissement et la ligne B.P. / téléphone (identité + contact). Renseignez ces textes ici ; le logo se définit dans la section Logo.

### Changer d’espace (démo)

Si votre compte cumule plusieurs rôles, vous pouvez basculer vers l’espace URL du rôle choisi (Administration, Direction, Enseignant…).

## EN

### Who can edit

School settings (year, logo, identity, documents) are viewable by staff. Only the **director** can edit them.

### Academic year

Only one year is current. Without a manual choice, the system auto-selects the year that contains today’s date. You can create the next year (e.g. 2026-2027) without making it current yet — useful for preparing the new intake — then set it as current when ready.

### School logo

The logo is used in the app UI (sidebar), report cards, timetable and other documents. Accepted formats: JPEG, PNG, WebP or SVG (max 2 MB).

### Identity and documents

On report cards, the header follows the official layout: **FR** column | **logo** | **EN** column. Each column shows republic, motto, ministry, regional and divisional delegations, then the school name and P.O. box / phone line (identity + contact). Edit those texts here; set the logo in the Logo section.

### Switch workspace (demo)

If your account has several roles, you can switch to the URL workspace of the chosen role (Administration, Director, Teacher…).
