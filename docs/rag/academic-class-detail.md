# Fiche classe

## FR

### Identité

Nom de la classe, niveau, section, cycle, série / voie.

### Organisation

- **Langue des documents** — langue par défaut des bulletins / PDF
- **Salle principale** — room d’accueil de la classe
- **Professeur principal** — titulaire de la classe
- **Barème** — schéma de notation (si renseigné)

### Matières de la classe (ClassSubject)

C’est ici que l’on :

1. **Affecte une matière** à la classe
2. Fixe le **coefficient**
3. Attribue l’**enseignant** titulaire de la matière
4. Choisit le **groupe** de sous-total bulletin
5. Indique les heures hebdomadaires et options (optionnelle, hors moyenne…)

Une matière du catalogue n’a ni coef ni enseignant tant qu’elle n’est pas affectée à une classe.

## EN

### Identity

Class name, level, section, cycle, track.

### Organisation

- **Document language** — default language for report cards / PDFs
- **Home room** — main classroom
- **Form teacher** — class tutor
- **Grading scheme** — when set

### Class subjects (ClassSubject)

This is where you:

1. **Assign a subject** to the class
2. Set the **coefficient**
3. Assign the **teacher**
4. Choose the report-card **group**
5. Set weekly hours and options

A catalogue subject has no coefficient or teacher until assigned to a class.
