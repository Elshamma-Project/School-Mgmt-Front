## FR

### Lecture seule

Sans le droit de gestion de la structure scolaire (Administration / Direction), la fiche est en consultation seule.

### Organisation

Langue des documents, salle principale, professeur principal et barème se règlent ici.

### Matières de la classe

C’est ici que vous affectez une matière, fixez le coefficient et choisissez l’enseignant (ClassSubject).

- Coefficient — poids dans la moyenne
- Enseignant — titulaire pour notes et EDT
- Groupe — sous-total sur le bulletin

### Élèves de la classe

Inscriptions de l’année scolaire liée à cette classe.

- Liste paginée (10, 20, 50 ou 100 par page)
- N° d’ordre, matricule, statut et particularités (redoublant, nouveau)
- Ajouter un élève via recherche nominative, modifier une inscription ou la retirer / la réactiver (Administration / Direction)
- N° d’ordre automatique selon l’ordre alphabétique dans la classe

## EN

### Read-only

Without school-structure management rights (Administration / Director), the record is read-only.

### Organisation

Document language, home room, form teacher and grading scheme are set here.

### Class subjects

This is where you assign a subject, set the coefficient and choose the teacher (ClassSubject).

- Coefficient — weight in the average
- Teacher — titular for grades and timetable
- Group — report-card subtotal

### Class students

Enrollments for the academic year linked to this class.

- Paginated list (10, 20, 50 or 100 per page)
- Roll number, student ID, status and flags (repeater, new)
- Add a student via name search, edit an enrollment or withdraw / reactivate it (Administration / Director)
- Roll number is automatic by alphabetical order in the class
