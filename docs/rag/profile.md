## FR

### Identité

Selon le type de compte, le nom peut être modifiable (personnel) ou protégé (élève / tuteur) car il figure sur les bulletins. Seule l’administration corrige alors les noms. La photo de profil n’apparaît jamais sur les bulletins.

### Mot de passe

Changez le mot de passe depuis cette page. Respectez la politique de complexité affichée.

### Sessions

Jusqu’à 2 sessions actives par compte. La plus ancienne est révoquée automatiquement si une 3ᵉ connexion réussit. Vous pouvez révoquer un appareil manuellement.

## EN

### Identity

Depending on the account type, the name may be editable (staff) or protected (student / guardian) because it appears on report cards. Only administration can then correct names. The profile photo never appears on report cards.

### Password

Change your password here. Follow the complexity policy shown.

### Sessions

Up to 2 active sessions per account. The oldest is revoked automatically if a 3rd sign-in succeeds. You can revoke a device manually.
